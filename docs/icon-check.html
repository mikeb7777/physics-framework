Icon Check

The Material Symbols font is requested with an explicit list of the icons a page wants. It saves weight, and it fails silently: an icon left off the list renders as its own name, in capitals, in the middle of a heading. Nothing appears in the console. This page loads every page in the sitemap and measures each icon to see whether a glyph actually arrived.

Ready.

Serve the site over http:// for this to work — opened straight from a file, the browser will not let this page read the pages it loads.

How it decides

A rendered icon glyph is almost exactly one em wide. The literal name is several times that, so the test measures each icon's text and compares it with the font size. It measures the text node through a Range, not the element box: these spans are display:block and stretch to their container, so the element can report 310px while the glyph is 32px. Measuring the element instead produces confident false alarms, which is how this check was first written and why it is written down here.

The list comparison alone is not enough either. It catches a name missing from icon_names, but not a name that is on the list and simply is not an icon. Only rendering catches both, so the two run together.
